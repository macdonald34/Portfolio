# Portfolio

## Editing projects

Edit the project entries in `projects.js`. Each entry controls a project card and its details:

- `title`, `category`, and `description` are the displayed text.
- `image` is the image path relative to the project folder; `alt` describes the image for accessibility.
- `filters` controls which work filters show the project (`branding`, `graphic`, `uiux`, `web`).
- `tools` lists the technologies or design tools shown in the details.
- `liveUrl` is the website link. Add the full URL (for example, `https://example.com`) to show a **Visit project** link; leave it empty to hide that link.

Keep the entries inside the `window.portfolioProjects` array and separate each entry with a comma.
